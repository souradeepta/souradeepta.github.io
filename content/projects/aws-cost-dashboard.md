A web-based dashboard that helps organizations monitor and optimize their AWS costs. Features include:

- Real-time cost visualization
- Usage trend analysis
- Cost anomaly detection
- Resource optimization recommendations
- Custom alerts and notifications

Built with Python Flask backend and React frontend, integrated with AWS Cost Explorer API.
