An enterprise-grade network configuration management system that supports:

- Multi-vendor device support (Cisco, Juniper, Arista)
- Version control integration
- Automated configuration backups
- Compliance checking
- Change management workflows

Built using Python with Ansible for orchestration and NAPALM for vendor-agnostic operations.
